# @physics/shared

Cross-cutting utilities shared by the packages and apps. Owns no user-facing surface and is not a roadmap phase of its own — it accretes across P0–P8 as common code is factored out.

- **Contract:** `docs/01-ARCHITECTURE.md` — the normative spec this package implements.
- **Roadmap phase:** **P0** (`docs/12-ROADMAP.md` §3).

## Status

Skeleton only. Exists from P0 and grows; deliberately empty until something is genuinely shared twice.

The definition of done for P0 is an **existing** CI gate, not a new criterion
(`docs/12-ROADMAP.md` §5) — implementation wires stubbed steps to real package
output and never redraws the finish line.
